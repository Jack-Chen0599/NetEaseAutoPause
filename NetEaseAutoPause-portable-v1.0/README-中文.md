# 网易云音乐自动暂停工具 · Windows 迁移包 v1.0

这是一套本地脚本和独立运行程序，不需要 Codex、Skill、AI 账号或 Token。
独立运行版已包含 Python 运行环境，安装时不需要下载依赖。请保存整个 ZIP。

## 换电脑使用：三步

1. 将 ZIP 复制到新电脑，先完整解压。不要在压缩包里直接运行，也不要只复制 exe。
2. 打开网易云音乐 → 设置 → 快捷键，启用全局快捷键，将播放/暂停设为 Ctrl+Alt+P。最小化后按一次，确认能控制网易云且不弹窗。
3. 双击 Install.cmd。出现 Running in background / Installed 后即安装完成，以后登录 Windows 自动启动。

要求：Windows 10/11 x64，网易云桌面版，保持全局快捷键启用。无需安装 Python、PowerShell 7、Codex。
当前实测网易云版本为 3.1.23.204764。不同电脑、网易云版本仍须做下面的实际播放检查。
本包未在另一台物理电脑测试；ARM Windows、macOS 不在本版支持范围内。

## 工作方式

- 浏览器或支持的视频播放器开始播放约 1 秒后，暂停正在播放的网易云音乐。
- 视频停止约 3 秒后，恢复工具自己暂停的同一首歌曲。
- 原本暂停的音乐不自动启动；网易云窗口不会因此显示、恢复或抢焦点。
- Ctrl+Alt+P 专用于网易云；如果被其他软件占用或被修改，需要先解决快捷键冲突。
- 浏览器里的音频也会触发。微信提示音不在应用监听名单中。
- 网易云需保持运行。请以普通用户权限运行网易云和本工具。
- 本版本通过音频状态判断音乐是否正在播放；无声片段可能延迟触发。
- 浏览器支持系统媒体会话时读取播放状态，否则参考音频活动；无声视频或较长静音片段可能无法完全按视频画面状态判断。

## 管理入口

| 文件 | 用途 |
| --- | --- |
| Install.cmd | 安装或更新，设置登录自启并立即启动 |
| Start.cmd | 重新启动后台工具 |
| Stop.cmd | 暂时停止，自启设置保留 |
| Check.cmd | 检查运行依赖、网易云进程与媒体接口；不会播放歌曲 |
| Uninstall.cmd | 停止、取消自启并卸载本工具，不卸载网易云 |
| source 文件夹 | Python 源码、依赖清单和重新打包脚本 |

安装目录自动取新电脑当前用户的 `%LOCALAPPDATA%\Programs\NetEaseAutoPause`。
日志为安装目录中的 activity.log；异常可查看 startup-error.log 和 diagnostics.json。
日志不记录歌曲名称或网页内容；自检报告不包含账号信息。
安装后可以删除解压目录，但建议保留 ZIP 备份。管理脚本也会复制到安装目录。

## 新电脑验收

1. 网易云播放歌曲，最小化到后台；浏览器打开一个有声视频。确认音乐暂停、网易云不弹窗。
2. 暂停视频，等待约 3 秒，确认音乐恢复。
3. 自己暂停网易云，再播放和暂停视频，确认音乐保持暂停。
4. 若无反应：先按 Ctrl+Alt+P 检查网易云快捷键，再运行 Check.cmd 查看诊断。

本机已验证无弹窗暂停/恢复及原本暂停不误启动。Check.cmd 通过仅表示依赖和接口正常，不代表所有新版本网易云或所有网站都已验证兼容。
